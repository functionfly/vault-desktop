## Rotation procedure

1. Generate a new key pair (don't overwrite the current one yet):
   ```bash
   cargo-tauri signer generate -w <operator key dir>/vault-key-v2.json
   ```
2. Update `VAULT_UPDATER_PUBKEY` on the build host. Tauri's
   `tauri-plugin-updater` accepts the public key as a string OR as a
   path to the .pub file; either form is fine.
3. Bump `createUpdaterArtifacts` in `tauri.conf.json` to keep the
   new build artefact on the same channel URL; the plugin will
   verify both signatures until every client has rotated.
4. After a 30-day grace window (matches the R2 noncurrent-version
   lifecycle), delete the old key file and update this fingerprint.
